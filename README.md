\# AI Incident Reporting API



\## 📌 Overview

A professional ASP.NET Core Web API for managing IT and Security incidents.



This project follows Clean Architecture principles and will include AI-powered features.



\---



\## 🚀 Goals

\- Clean Architecture

\- Incident lifecycle management

\- Role-based access (Admin / Engineer / Reporter)

\- AI-assisted classification and summary (later)

\- Unit \& Integration testing

\- CI/CD (GitHub Actions)

\- Future integration with n8n and MCP



\---



\## 🏗️ Architecture



\- API → Controllers \& endpoints

\- Application → Use cases \& business logic

\- Domain → Core entities \& rules

\- Infrastructure → Database \& external services



\---



\## 🛠️ Tech Stack



\- .NET 8

\- ASP.NET Core Web API

\- Entity Framework Core

\- SQL Server (later)

\- xUnit (testing)
